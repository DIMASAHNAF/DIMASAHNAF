## 🚀 Featured Projects

### ⚡ [Smart AI Face Recognition & Geofencing Attendance](https://github.com/DIMASAHNAF/presensi-sekolah-online)
Sistem presensi mandiri anti-fraud berlapis tiga (*Triple Security Layer*) yang menggabungkan biometrik wajah dan verifikasi perimeter jaringan:
* **AI Biometric Face ID:** 128-D Vector ResNet (`dlib` + `face-recognition` Python) dengan *Euclidean Distance threshold* ketat ($\le 0.45$) dan HUD oval real-time di browser.
* **Dynamic GPS Geofencing:** Validasi radius kehadiran menggunakan formula matematis *Haversine* berbasis koordinat peta *Leaflet.js*.
* **MikroTik Subnet & IP Whitelist:** Pembatasan koneksi wajib ke WiFi sekolah via subnet CIDR (`/21`) dan pencegahan penggunaan fake GPS / paket data seluler.
* **Realtime Sync:** Update otomatis kehadiran dan statistik guru/wali kelas tanpa reload halaman.

### 💳 [SPP Online · Portal Pembayaran Sekolah](https://github.com/DIMASAHNAF/spp-online)
Sistem pembayaran tagihan pendidikan hybrid (Tunai & Online) dengan transaksi tingkat enterprise:
* **Stack:** Next.js 16 (App Router & Server Actions), PostgreSQL, dan Prisma 6.
* **Payment Gateway & Webhook:** Integrasi Midtrans Snap dengan validasi signature SHA-512, locking transaksi atomik, serta handling idempotensi.
* **Paperless Kwitansi:** Pembuatan dokumen kwitansi digital *immutable snapshot* secara dinamis.
